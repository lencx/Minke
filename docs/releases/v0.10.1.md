<h2 id="cn-v0.10.1">本次更新</h2>

- **升级到 DSH 0.2.2-rc.5。** 桌面采用 DSH 的会话导出提示、Start 页滚动和 macOS 全屏标签栏布局，搜索和抓取使用新版路由。
- **减少打开大会话时的加载量。** 普通历史请求每页上限为 100 条消息，可以向前加载更早的内容。折叠流程组首次显示时才挂载成员。
- **修复 Linux 凭据授权。** Hyprland 等桌面环境可使用已经运行的 Secret Service 钥匙串，KDE 可继续使用 KWallet，并支持命令行指定后端。 [PR #22](https://github.com/lencx/Minke/pull/22)
- **改进侧栏和文件管理。** Start 页的 More tools 位于 Minke 分组上方，Connections 左栏统一对齐。工具栏图标更清晰，文件夹访问受限时可选择其他目录。

**升级提示。** 曾选用本地 HTTP 抓取的用户可在网页搜索与获取设置中切换到 DeepSeek Fetch API。依赖旧版设置插槽或 Python PTC 运行时的自定义插件请查看迁移说明。 [DSH 升级说明](https://github.com/lencx/Minke/blob/v0.10.1/docs/dsh-upgrade.md)

<h2 id="en-v0.10.1">What's new</h2>

- **Upgrade to DSH 0.2.2-rc.5.** The desktop uses native session export feedback, Start page scrolling, and macOS fullscreen tab layout. Search and fetch use the updated routing.
- **Load less when opening large sessions.** Ordinary history requests are capped at 100 messages per page. You can load earlier pages on demand. Collapsed process groups mount their contents when first shown.
- **Fix credential authorization on Linux.** Hyprland and similar desktops can use a running Secret Service keyring. KDE supports KWallet, and users can select a backend on the command line. [PR #22](https://github.com/lencx/Minke/pull/22)
- **Improve the sidebar and file manager.** More tools appears above Minke on the Start page, and the Connections navigation uses consistent left alignment. Toolbar icons are easier to see, and Files can offer another folder when access is denied.

**Upgrade notes.** If you previously selected local HTTP fetching, you can switch to DeepSeek Fetch API in Web search and fetch settings. Custom plugins using older settings slots or the Python PTC runtime should follow the migration guide. [DSH upgrade guide](https://github.com/lencx/Minke/blob/v0.10.1/docs/dsh-upgrade.md)
